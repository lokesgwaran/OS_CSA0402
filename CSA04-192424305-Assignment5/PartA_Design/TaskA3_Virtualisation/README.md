# Task A3 – Evaluate Virtualisation
- **Type-1 Hypervisors (KVM, ESXi, Xen):** Run directly on bare-metal hardware with Intel VT-x/AMD-V acceleration; ideal for production isolation and live migration.
- **Type-2 Hypervisors (VirtualBox, VMware Workstation):** Run atop a host OS; suited for desktop labs and demos due to host OS memory/I/O overhead.
