# Task 3 – Modern File Systems
- **Comparison:** FAT32 vs. NTFS vs. ext4 vs. XFS vs. Btrfs/ZFS/APFS.
- **Crash Consistency:** Journaling modes (`data=journal`, `data=ordered`, `data=writeback`) vs. Copy-on-Write atomic root switching.
- **Device Recommendations:** exFAT for cross-OS USB drives; ext4/XFS for Linux databases; ZFS/Btrfs for snapshot backup servers.
