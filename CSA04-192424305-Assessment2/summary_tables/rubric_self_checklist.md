# Assessment Tool 2 – Rubric Alignment Checklist (CO1)

| Criterion | Weightage | Target Level 4 (Exemplary) Evidence in Submission |
| :--- | :---: | :--- |
| **Concept Identification** | 25% | Covers Process, File, Device, and Information system calls along with operations and OS services. |
| **Linkages** | 25% | Directional arrows (`->`) and linking phrases connect System Call Interface -> Categories -> Operations -> OS Services. |
| **Organization** | 20% | Top-down hierarchical tree from Operating System down to Efficient OS Services, paired with structured tables. |
| **Integration of Literature** | 20% | Aligns with standard OS kernel architecture (Silberschatz et al. system call taxonomy and dual-mode execution). |
| **Clarity** | 10% | Clean ASCII/visual hierarchy, summary functional table, and concise conclusion. |
